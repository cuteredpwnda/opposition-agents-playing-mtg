\section{Theoretical background (1 page)}
\label{sec:tech-theory}

The framework treats Magic: The Gathering (MTG) as a partially-observable
Markov game.  Each player's perspective is a POMDP
$(\mathcal{S},\mathcal{O},\mathcal{A},T,\Omega,R,\gamma)$ with hidden
state (opponent hands and library order).  Concretely:
%
\begin{itemize}[leftmargin=*]
  \item $\mathcal{S}$: full \texttt{GameState} including all players' zones, the
        stack, mana pools, life totals, and bookkeeping flags.  Conservatively
        $|\mathcal{S}| > 10^{800}$.
  \item $\mathcal{O}$: seat-filtered snapshot emitted by phase-rs
        \texttt{StateUpdate}, then projected into our policy view by
        \texttt{src/integrations/phase\_rs/adapter.py}.
  \item $\mathcal{A}$: legal action list from phase-rs wire messages,
        mapped into internal \texttt{Action} values by the same adapter,
        typically
        $|\mathcal{A}| \in [1, 60]$.
  \item $T$: phase-rs runtime transition system (Rust engine), deterministic
        given the random seed and chosen actions.
  \item $R$: terminal $\pm 1$ on win/loss; agents may shape via $\Delta$life,
        $\Delta$cards, $\Delta$tempo when training a value head.
\end{itemize}

\noindent\textbf{Three families of policies.}  The agents implement:
%
\begin{enumerate}[leftmargin=*]
  \item \emph{Reactive} (Random, Heuristic, KG-Heuristic, LLM): map
        $o_t \to a_t$ directly, no internal state.
  \item \emph{Model-based} (World-Model): learn $\hat T$ in latent space
        and pick $\arg\max_a \mathbb{E}_{\hat T}[V(s_{t+H})]$.
  \item \emph{Belief-driven} (Active-Inference, LLM-Fusion):
        maintain a belief $b_t$ over hidden state and minimise expected
        free energy $G(\pi) = \underbrace{-\mathbb{E}_q[R]}_{\text{pragmatic}}
        \,+\, \underbrace{-\mathbb{E}_q[\mathrm{KL}(b_{t+1}\|b_t)]}_{\text{epistemic}}$.
\end{enumerate}
%
A self-contained derivation is in \S\ref{sec:tech-foundations}.  See
also the corresponding section in the companion paper.

The same formal stack also supports a collective-intelligence workflow:
different agent families generate trajectories, those trajectories are
mined into append-only KG evidence with provenance, and later agents use
that shared graph memory as an additional prior. This separates immutable
card facts from learned strategic evidence while allowing cumulative
cross-agent learning across runs.

\section{The contract every agent satisfies}
\label{sec:contract}

Every agent class implements a single method:
%
\begin{lstlisting}
class MTGAgent(Protocol):
    name: str

    async def decide_action(
        self,
        game_state: GameState,
        legal_actions: list[Action],
    ) -> Action: ...
\end{lstlisting}
%
Agents must \emph{never} mutate \texttt{game\_state}; only the engine is
allowed to.  An agent that returns an action not in
\texttt{legal\_actions} is treated as a forfeit by
the phase-rs integration runner.

Determinism: any RNG owned by an agent must be a \texttt{random.Random}
instance constructed from the seed passed by the runner.  This
guarantees \texttt{(seed, decklists, agent\_types)} replays bit-exactly.

\section{Per-agent reference}

\subsection{RandomAgent}
\textbf{File:} \texttt{src/agents/random\_agent.py}.  \textbf{Purpose:}
baseline / smoke test.

\begin{lstlisting}
def decide_action(self, game_state, legal_actions):
    return self._rng.choice(legal_actions)
\end{lstlisting}
%
Configuration: \texttt{seed: int} (forwarded to \texttt{random.Random}).
Failure modes: none.  Deterministic given a seed.

\subsection{HeuristicAgent}
\textbf{File:} \texttt{src/agents/heuristic\_agent.py}.

\medskip\noindent\textbf{Decision flow.}
\begin{algorithmic}[1]
\State $\text{scored} \gets [(\text{priority}(a), -\text{tiebreak}(a), a)\text{ for }a \in \text{legal\_actions}]$
\State $\text{scored.sort}(\text{descending})$
\State \Return $\text{scored}[0].a$
\end{algorithmic}

\noindent\textbf{Priority table} (\texttt{ACTION\_PRIORITIES}):
\begin{center}\small
\begin{tabular}{lc}
\toprule
Action type & Priority \\
\midrule
PLAY\_LAND          & 100 \\
CAST\_SPELL         &  90 \\
DECLARE\_ATTACKERS  &  80 \\
DECLARE\_BLOCKERS   &  70 \\
ACTIVATE\_ABILITY   &  60 \\
PASS\_PRIORITY      &   1 \\
CONCEDE             &   0 \\
\bottomrule
\end{tabular}
\end{center}

Tiebreaks: prefer cheaper spells, prefer creatures with higher power
when attacking.  Failure modes: never holds up mana for instants
(known limitation).

\subsection{KGHeuristicAgent}
\textbf{File:} \texttt{src/agents/kg\_heuristic\_agent.py}.

Wraps \texttt{HeuristicAgent} but rescores \texttt{CAST\_SPELL} actions
using the Neo4j graph through
\texttt{src/knowledge/kg\_query.py:score\_card\_for\_state}:
%
\begin{equation}
\text{kg\_score}(c) =
  10 \cdot \mathbf{1}[c \in \text{NearComboMissingPieces}(s)]
  + \sum_{p \in \text{permanents}(s)} \text{strength}(\text{KG-edge}(c,p)).
\end{equation}
%
The combined score is $\text{prio}(a) + \lambda \cdot \text{kg\_score}(c)$ with
$\lambda{=}5$.  Configuration: \texttt{neo4j\_uri}, \texttt{auth},
\texttt{enable\_combo\_lookup} (bool).  Failure mode: if Neo4j is
unreachable, falls back silently to plain HeuristicAgent.

\subsection{OllamaAgent (and LLMAgent alias)}
\textbf{File:} \texttt{src/agents/ollama\_agent.py}.

Builds a textual board state via \texttt{format\_state\_for\_llm()}, sends a
chat completion request to \texttt{http://localhost:11434/api/chat}
(model \texttt{gemma4:e2b}, temperature 0.2, \texttt{keep\_alive=30m},
timeout 120s), and parses an integer action index out of the reply.

\begin{lstlisting}
prompt = (
    "You are an MTG expert.  Choose the BEST action by index.\n"
    f"State:\n{format_state_for_llm(state)}\n"
    f"Legal actions:\n{enumerate_actions(legal_actions)}\n"
    "Respond with ONLY the index."
)
resp = requests.post(OLLAMA_URL, json={"model": MODEL, "messages": [...]})
idx = int(re.search(r"\d+", resp.json()["message"]["content"]).group())
return legal_actions[idx % len(legal_actions)]
\end{lstlisting}
%
Failure modes: timeout $\to$ fall back to HeuristicAgent; non-integer
reply $\to$ fall back to RandomAgent over a small legal-action subset.

\subsection{ActiveInferenceAgent}
\textbf{File:} \texttt{src/agents/active\_inference\_agent.py}.

Maintains a Dirichlet belief over the opponent's hand composition and
minimises expected free energy:
%
\begin{equation}
G(\pi) \;=\; -\,\mathbb{E}_{q(s'|\pi)}[R(s')]
            \;-\; \mathrm{KL}\!\left[q(s'|\pi)\,\|\,b_t\right].
\end{equation}
%
The first term is the pragmatic value (favouring high-utility outcomes),
the second is the epistemic value (favouring information gain).  Belief
update on each opponent action uses Bayes' rule with a card-likelihood
table seeded from the decklist (see \texttt{docs/OPPONENT\_MODELING\_WITH\_DECKLIST.md}).

\subsection{WorldModelAgent}
\textbf{File:} \texttt{src/agents/world\_model\_agent.py}.
\textbf{Backbone:} \texttt{src/world\_model/world\_model.py}.

Training now uses the external \texttt{stable-pretraining} orchestration layer and the surrounding \texttt{stable-worldmodel} research stack rather than a bespoke in-repo trainer. Concretely, \texttt{scripts/train\_stable\_worldmodel.py} wraps the local MTG \texttt{WorldModel} in a \texttt{stable\_pretraining.Module} and drives optimisation through \texttt{stable\_pretraining.Manager}; this mirrors the software split used by LeWorldModel, which keeps the architecture and loss local while delegating training/runtime plumbing to the upstream libraries \cite{balestriero2025stable,maes_lelidec2026swm,maes_lelidec2026lewm}.

\medskip\noindent\textbf{Components} (V+M+C, after Ha \& Schmidhuber).
\begin{align*}
z_t          &= \mathrm{Enc}_V(o_t)               &&\text{(perceptual encoder, 768-d)} \\
g_t          &= \mathrm{Enc}_{KG}(\mathcal{G}, s_t) &&\text{(GraphSAGE, 128-d)} \\
(h_t, c_t)   &= \mathrm{LSTM}_M([z_t;g_t], (h_{t-1}, c_{t-1})) \\
\hat r_t     &= V(h_t)                            &&\text{(value head)} \\
\pi(a|h_t)   &= \mathrm{softmax}(C(h_t))          &&\text{(controller)}
\end{align*}
%
\noindent\textbf{Decision rule.}  For each candidate action $a \in \mathcal{A}$,
roll out $K$ trajectories of horizon $H$ in latent space (no actual
rules-engine simulation):
%
\begin{equation}
\text{score}(a) = \frac{1}{K} \sum_{k=1}^{K} V(h^{(k)}_{t+H} \mid a_t=a).
\end{equation}
%
Defaults: $K=8$, $H=10$, sampling temperature $1.15$.

\medskip\noindent\textbf{Checkpoint loading.}  \texttt{WorldModel.load} now
tolerates three checkpoint shapes (canonical, JEPA-only, and
free-form), warning-and-continuing rather than raising.  The agent
factory (\texttt{src/agents/\_\_init\_\_.py:\_make\_world\_model}) falls
back to a default-initialised network if the checkpoint file does not
exist, so the harness can be smoke-tested before training.

\medskip\noindent\textbf{Checkpoint troubleshooting.}
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
      \item Shape mismatch in controller head: occurs when $|\mathcal{A}_{legal}|$ conventions differ between checkpoint and runtime. Re-export checkpoint after rebuilding action encoding.
      \item Missing JEPA keys: expected when loading pre-JEPA checkpoints; loader falls back to random init for missing tensors and logs a warning.
      \item KG context mismatch: if graph feature width changed, pass a matching checkpoint or train one epoch with \texttt{--resume} to adapt projection layers.
\end{itemize}

\subsection{LLMFusionAgent}
\textbf{File:} \texttt{src/agents/llm\_fusion\_agent.py}.

Combines four signals into a single ranking:
%
\begin{equation}
\text{score}(a) =
   \alpha_h\, s_{\text{heur}}(a)
 + \alpha_g\, s_{\text{KG}}(a)
 + \alpha_w\, s_{\text{WM}}(a)
 + \alpha_\ell\, \log p_{\text{LLM}}(a),
\end{equation}
%
with default weights $(\alpha_h, \alpha_g, \alpha_w, \alpha_\ell) =
(0.15, 0.15, 0.40, 0.30)$ from \texttt{FusionConfig}.  When any signal
exceeds the \texttt{obvious\_threshold} ($0.8$), it short-circuits the
vote to save an LLM call.

\begin{algorithm}[h]
\caption{LLM-Fusion turn (simplified)}
\begin{algorithmic}[1]
\Require state $s_t$, legal actions $\mathcal{A}$, weights $\alpha$
\State $S_h \gets \text{HeuristicAgent.score\_all}(s_t, \mathcal{A})$
\State $S_g \gets \text{KG.score\_all}(s_t, \mathcal{A})$
\If{$\max_a S_h(a) > \tau_{\text{obvious}}$} \Return $\arg\max_a S_h(a)$ \EndIf
\State $S_w \gets \text{WM.value\_rollout}(s_t, \mathcal{A})$
\State $\mathcal{A}^* \gets \text{top-}N\text{ actions by }S_w$
\State $S_\ell(a) \gets \log p_{\text{LLM}}(a \mid \text{prompt}(s_t, \mathcal{A}^*))$
\State \Return $\arg\max_{a \in \mathcal{A}^*}
        \alpha_h S_h(a) + \alpha_g S_g(a) + \alpha_w S_w(a) + \alpha_\ell S_\ell(a)$
\end{algorithmic}
\end{algorithm}

\medskip\noindent\textbf{FusionConfig defaults.}
\begin{center}\small
\begin{tabular}{lcc}
\toprule
Parameter & Default & Role \\
\midrule
\texttt{heuristic\_weight} & $0.15$ & Rules-aware tactical prior \\
\texttt{kg\_weight} & $0.15$ & Combo and synergy prior from Neo4j \\
\texttt{wm\_weight} & $0.40$ & Latent rollout value estimate \\
\texttt{llm\_weight} & $0.30$ & Language prior over legal indices \\
\texttt{top\_n} & $5$ & Candidate set handed to LLM stage \\
\texttt{obvious\_threshold} & $0.8$ & Short-circuit threshold for cheap decisions \\
\bottomrule
\end{tabular}
\end{center}

\medskip\noindent\textbf{One-turn message flow (ASCII).}
\begin{lstlisting}[language={}]
priority_loop -> LLMFusionAgent.decide_action(state, legal_actions)
      LLMFusionAgent -> HeuristicAgent.score_all: S_h
      LLMFusionAgent -> KG query layer: S_g
      alt max(S_h) > obvious_threshold
            LLMFusionAgent --> priority_loop: argmax(S_h)
      else
            LLMFusionAgent -> WorldModelAgent.rollout_values: S_w
            LLMFusionAgent -> OllamaAgent.log_probs(topN by S_w): S_l
            LLMFusionAgent -> fuse(alpha_h*S_h + alpha_g*S_g + alpha_w*S_w + alpha_l*S_l)
            LLMFusionAgent --> priority_loop: chosen legal action
      end
priority_loop -> engine: apply chosen action
\end{lstlisting}

\section{Debugging recipes}

\subsection{Agent loops on pass priority}
Symptoms: repeated \texttt{PASS\_PRIORITY} despite non-trivial board states.

Checklist:
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
      \item Inspect \texttt{legal\_actions} logs from \texttt{src/orchestrator/priority\_loop.py}; if only pass/concede exist, the issue is engine-side rather than policy-side.
      \item Verify stack resolution path in \texttt{src/engine/stack.py} and trigger enqueueing in \texttt{src/engine/triggered\_abilities.py}.
      \item Confirm current phase allows the expected action class (main phase vs combat priority windows).
\end{itemize}

\subsection{Agent never attacks}
Symptoms: board develops, but attackers are never declared.

Checklist:
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
      \item Check \texttt{src/engine/combat.py:legal\_attackers} output for summoning-sickness and tap-state filtering.
      \item Ensure power/toughness modifiers from equipment and temporary effects reach \texttt{effective\_power}/\texttt{effective\_toughness}.
      \item For heuristic agents, inspect \texttt{ACTION\_PRIORITIES} and tiebreak functions for accidental over-penalisation of combat lines.
\end{itemize}

\subsection{World-model agent regresses after checkpoint swap}
Symptoms: sudden Elo drop or random-looking actions after loading a new checkpoint.

Checklist:
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
      \item Confirm checkpoint compatibility warnings from \texttt{WorldModel.load}; missing keys should be expected and logged.
      \item Run a deterministic smoke pod (seed fixed) and compare trace-level \texttt{wm} scores before/after swap.
      \item Recompute normalisation statistics if latent feature scales changed between training runs.
\end{itemize}

\subsection{LLM fusion hangs or times out}
Symptoms: long think times or fallback-only behaviour.

Checklist:
\begin{itemize}[leftmargin=1.2em, itemsep=1pt]
      \item Verify Ollama endpoint and model are available (see \texttt{docs/OLLAMA\_SETUP.md}).
      \item Lower \texttt{top\_n} and increase \texttt{obvious\_threshold} to reduce LLM calls under load.
      \item Confirm timeout fallback path returns a legal action and records the fallback reason in reasoning traces.
\end{itemize}

\section{Theoretical foundations (extended)}
\label{sec:tech-foundations}

\subsection{POMDPs and partial observability}
A finite-horizon POMDP is the tuple
$(\mathcal{S},\mathcal{A},\mathcal{O},T,\Omega,R,\gamma,b_0)$.  The
optimal value function over beliefs satisfies
%
\begin{equation}
V^*(b) = \max_a \Big[\,
   \sum_s b(s) R(s,a)
   + \gamma \sum_o \Pr(o\mid b,a)\, V^*(b'_o)
\,\Big],
\end{equation}
%
where $b'_o$ is the Bayes update of $b$ after action $a$ and observation
$o$.  Exact solution is intractable for $|\mathcal{S}| > 10^{800}$;
all our policies are approximations.

\subsection{World models as latent imagination}
Following Ha \& Schmidhuber and Hafner et~al.\ (Dreamer), we factor the
agent as $V$ (encoder), $M$ (recurrent dynamics), and $C$ (controller).
Training the dynamics jointly minimises
%
\begin{equation}
\mathcal{L}_{\text{dyn}} = \sum_t \big\| \hat z_{t+1} - \mathrm{sg}(z_{t+1}) \big\|^2_2
   + \beta \cdot \mathrm{KL}(q(z_t|o_t) \,\|\, p(z_t|h_{t-1})),
\end{equation}
%
where $\mathrm{sg}$ is stop-gradient.  We follow the JEPA recipe of
LeCun \& Assran: predict in representation space, not in pixel space.
The single tunable knob is $\beta$ (\texttt{--jepa-beta}, default $1.0$).
In the current repository this loss is still computed by the local MTG model, but the optimisation loop, callback stack, and checkpoint orchestration are delegated to \texttt{stable-pretraining}; \texttt{stable-worldmodel} remains the upstream runtime substrate around data collection and world-model evaluation conventions \cite{balestriero2025stable,maes_lelidec2026swm}.

\subsection{Free energy and active inference}
Friston's free-energy principle frames perception and action as joint
inference.  The variational free energy is
%
\begin{equation}
F[q] = \underbrace{\mathbb{E}_q[\log q(s) - \log p(o,s)]}_{\text{evidence bound}}
     = \mathrm{KL}(q\|p(s|o)) - \log p(o).
\end{equation}
%
Action selection minimises \emph{expected} free energy,
which decomposes as
%
\begin{equation}
G(\pi) = \underbrace{-\mathbb{E}_q[\log p(o\mid C)]}_{\text{pragmatic}}
        + \underbrace{-\mathbb{E}_q[\mathrm{KL}(q(s\mid o,\pi) \,\|\, q(s\mid \pi))]}_{\text{epistemic}}.
\end{equation}
%
The pragmatic term encodes goal-seeking; the epistemic term encodes
information-gathering.  Bayesian RL is recovered when the prior $C$
is uniform, and pure exploration is recovered when rewards are flat.

\subsection{Knowledge-graph grounding}
Cards form an inductive graph $\mathcal{G}=(V,E)$ with edges for
\emph{combo}, \emph{synergy}, \emph{counters}, and \emph{enables}
(see \texttt{src/knowledge/}).  GraphSAGE produces inductive node
embeddings $\mathbf{h}_v \in \mathbb{R}^{128}$ that are concatenated
with the perceptual latent $z_t$ before the recurrent dynamics.  This
is the V+M+C model with an additional \emph{graph} channel
$\mathrm{Enc}_{KG}$.

\subsection{LLM-as-policy under legal-action constraints}
The LLM never freely generates text.  Given the prompt
$\rho(s_t,\mathcal{A})$, we read off
%
\begin{equation}
\log p_{\text{LLM}}(a\mid s_t) =
  \mathrm{LM}(\text{idx}(a) \mid \rho(s_t,\mathcal{A}))
\end{equation}
%
and mask any index outside $\{0, \dots, |\mathcal{A}|-1\}$.  This is the
standard ``constrained decoding'' trick and prevents illegal
hallucinated moves.

\subsection{Self-play promotion as fixed-point iteration}
The iterative training loop in \texttt{scripts/train\_pipeline.py}
implements a champion-vs-challenger schema: a challenger trained on
the latest replay buffer plays a best-of-$N$ against the current
champion; promotion happens iff the win rate exceeds $0.55$.  This is
a stochastic-approximation fixed-point on the policy improvement
operator and converges (in expectation) provided the dynamics model is
locally accurate.
