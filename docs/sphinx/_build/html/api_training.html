Training API¶

Reinforcement Learning training loop — agents play against each other.

Combines: - Self-play game generation via GameRunner - Experience collection from real games - SelfPlayCollector for world model trajectory data - Neural module training (NeuralReasoningModule or WorldModel) - ELO-based evaluation and curriculum

This is the production RL loop that wires everything together.
